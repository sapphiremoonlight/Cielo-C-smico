# ⭐ CIELO CÓSMICO 2.0 — APP BLUEPRINT

Cielo Cósmico 2.0 is a productivity & learning app with celestial aesthetics. This version adds **4 new tabs** and upgrades existing ones for a more interactive and gamified experience.

---

## 🌟 Tabs Overview

### **Dashboard (New)**
- Daily check-in
- Today’s goals
- Streak counter
- Pretty progress rings (showing today’s completion %)

### **Weekly Plan (Existing, but Upgraded)**
- Animated celestial card layout
- Checkboxes that save to `localStorage`
- Smooth green glow check animations

### **3-Month Pathway + Progress Bars (New)**
- Visual roadmap of learning objectives
  - Month 1: Basics
  - Month 2: Listening + Grammar
  - Month 3: Conversation
- Each task has a checkbox
- Global progress bar updates as you complete steps
- Three smaller progress bars (one per month)

### **Daily Log (Enhanced)**
- Automatically timestamps logs
- Category selection:
  - Vocabulary
  - Music Analysis
  - Grammar
  - Reading
  - Writing
  - Free Journal
  - Flashcards
  - Tests
  - Other
- Search bar (by text or date)
- Filters (by category)
- Pretty log cards
- Pagination or infinite scroll if needed

### **Análisis de Música**
- Form with **5 analysis questions**
- Auto-saves each song entry
- Stores a full list of song analyses
- Click to expand a previous analysis
- Optional star rating + album art upload
- SUPER aesthetic music card layout

### **Flashcards**
- Generate flashcards (term + definition)
- Study mode (flip cards)
- LocalStorage-based “decks”
- Practice mode (shuffle / random order)
- Track your accuracy

### **Test Maker**
- Create tests (10–30 questions)
- Timer (optional)
- Multiple choice or write-in
- Auto-grading
- Stores past test results
- “Retry test” option
- Progress meter for test performance

### **Gamification**
- XP system
- Levels (1–50)
- Badges:
  - 5-day streak
  - 7-day music streak
  - “Grammar Queen/King/Regal”
  - “Lexicon Collector” (200 vocab words logged)
- Animated badge unlock pop-ups
- Achievement gallery

### **Themes**
- Switcher menu with themes:
  - 🌿 Emerald Cosmos
  - 💚 Mint Galaxy
  - 🌙 Moonlit Jade (dark + soft glow)
  - ✨ Stardust Silver + Green accents
- Theme preference saved to `localStorage`
- Smooth fade transition
